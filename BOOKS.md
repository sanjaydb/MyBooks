# Book and chapter roadmap

This repository is organized as companion material for books in progress. Each top-level directory represents a book or major subject area; its subdirectories group examples into chapter-sized topics.

| Proposed book / part | Current chapter groups |
| --- | --- |
| Practical Linux Shell Scripting | Administration; user utilities; developer utilities |
| Windows Systems Programming in C | Administration; users; sockets; IPC; SMB; Internet; backup and restore; encryption |
| Practical Reverse Engineering and Malware Analysis | Windows analysis; PE, DLL, and COFF inspection; documents; indicators |
| Windows x86 Assembly | Arithmetic; strings; arrays; bit operations; processor information |
| Safe Machine-Code Fundamentals | Windows x86; Linux x86-64 |
| Memory Safety on Windows | Stack safety; heap safety |

## Chapter convention

As the manuscripts mature, each chapter can use a directory such as `chapter-01-topic/` containing:

- `README.md` with learning goals, prerequisites, build commands, and expected output
- Numbered source examples in reading order
- A short exercise section and references

Existing filenames remain descriptive so readers can find examples before final chapter numbers are assigned.
