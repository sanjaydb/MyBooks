# Code of conduct

Be respectful, constructive, and focused on improving the educational material. Welcome questions asked in good faith, explain corrections clearly, and critique code rather than people.

Harassment, discrimination, threats, doxxing, spam, and attempts to introduce harmful material are not accepted. Repository maintainers may edit or remove contributions and restrict participation to keep the project safe and welcoming.

For sensitive conduct concerns, use a private GitHub vulnerability report rather than a public issue.
