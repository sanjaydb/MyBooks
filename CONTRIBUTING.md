# Contributing

Thank you for helping improve the sample code and the books it accompanies.

## Good contributions

- Corrections to code, explanations, spelling, and build instructions
- Safer or clearer versions of an existing example
- Portability notes and confirmed compiler or operating-system results
- Focused examples that fit an existing book topic

## Before submitting

1. Search existing issues and pull requests.
2. Keep each change focused and explain why it is useful.
3. Test the example on the platform named in its README.
4. Do not include binaries, archives, secrets, personal data, proprietary code, live malware, or weaponized payloads.
5. For C, enable compiler warnings and address new warnings when practical. For shell scripts, run `bash -n` and ShellCheck.
6. Update the relevant README and [TESTING.md](TESTING.md) when behavior or support changes.

By contributing, you agree that your contribution may be distributed under this repository's `CC0-1.0 OR MIT` dual license.

Security or privacy concerns should be reported privately as described in [SECURITY.md](SECURITY.md).
