# Linux Developer Utilities

Ten small Bash tools for common development tasks.

| Script | Purpose |
| --- | --- |
| `git_summary.sh` | Show a compact Git repository summary. |
| `code_stats.sh` | Count source files and lines by extension. |
| `find_todos.sh` | Find TODO, FIXME, and HACK comments. |
| `serve_directory.sh` | Start a local static-file web server. |
| `format_json.sh` | Validate and pretty-print JSON. |
| `process_on_port.sh` | Show the process using a TCP or UDP port. |
| `project_archive.sh` | Create a clean source archive without build artifacts. |
| `compare_files.sh` | Display a readable unified diff between two files. |
| `check_dependencies.sh` | Check whether required commands are installed. |
| `new_bash_script.sh` | Create a safe starter Bash script. |

## Usage

```bash
chmod +x *.sh
./git_summary.sh
./code_stats.sh ~/projects/my-app
```

Use `--help` with any script for its full usage information.
