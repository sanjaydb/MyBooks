# Linux User Utilities

Ten simple Bash scripts for everyday Linux tasks.

| Script | Purpose |
| --- | --- |
| `find_file.sh` | Find files by partial name. |
| `directory_size.sh` | Show the total size of a directory. |
| `recent_files.sh` | List files modified recently. |
| `search_text.sh` | Search recursively for text in files. |
| `file_checksum.sh` | Generate or verify a SHA-256 checksum. |
| `extract_archive.sh` | Extract common archive formats. |
| `process_search.sh` | Find running processes by name. |
| `random_password.sh` | Generate a random password locally. |
| `quick_note.sh` | Add, list, search, or clear personal notes. |
| `count_files.sh` | Count files and directories beneath a path. |

## Usage

```bash
chmod +x *.sh
./find_file.sh ~/Documents report
```

Run any script with `--help` for its usage information.
